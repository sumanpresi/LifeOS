Reclaim space

Removes whiteboard copies left behind by earlier updates, and redundant points from pen strokes. Your drawings look exactly the same. A snapshot is taken first, so this is fully undoable from Restore.

A backup is a file that leaves this device. Download one regularly and keep it in Google Drive, OneDrive, or on a disk — Supabase and this browser can both fail, and a copy you hold cannot.

Data health

Checks your data for faults that could hide your work or make a page fail to load. Nothing you've written is ever deleted by a repair.

Snapshot history

Automatic local restore points, taken every few hours. Good for undoing a bad edit or a mass deletion — but they live in this browser, so they are not a substitute for a downloaded backup.

One-time setup

This copy of LifeOS isn't linked to a Supabase project yet. It takes about ten minutes, once, and everything is free:

  1. Create a free project at supabase.com.
  2. In the project's SQL Editor, run the contents of supabase-setup.sql (shipped alongside this file).
  3. Create a GitHub OAuth app at github.com/settings/developers. Set the callback URL to https://YOUR-PROJECT-REF.supabase.co/auth/v1/callback.
  4. In Supabase → Authentication → Providers → GitHub, paste the OAuth app's Client ID and Secret.
  5. In Supabase → Authentication → URL Configuration, set your site's address (e.g. your GitHub Pages URL) as the Site URL.
  6. Open js/config.js in a text editor and fill in SUPABASE_URL and SUPABASE_ANON_KEY.

Note: GitHub sign-in only works from a hosted address (GitHub Pages, Vercel, or a local server) — not from a file opened directly off the disk. Until then, LifeOS keeps working in local-only mode.

Sign in

Sign in with GitHub to sync LifeOS to your own private database and use it from any device — phone, tablet, office PC. Changes save automatically.
